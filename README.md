# orbit
(very basic) Orbit simulation in C.
![](https://github.com/lauchimoon/orbit/blob/main/screenshot.png)

## Getting started
You need a C compiler and GNUMake.
```sh
$ git clone https://github.com/lauchimoon/orbit.git
$ cd orbit
$ make
$ ./orbit
```
Make sure to specify `RAYLIB_PATH` when calling `make`.
